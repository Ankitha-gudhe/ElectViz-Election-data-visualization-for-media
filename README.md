# ElectViz-Election-data-visualization-for-media
## Overview

ElectViz is an interactive data visualization project designed to present election results in a clear, engaging and media-friendly format. 
It transforms raw election data into meaningful insights using dashboards and visual analytics.
This project is ideal for journalists, analysts and the general public to quickly understand voting trends, party performance and regional insights.

## Features

 
-  Interactive dashboards for election analysis

- Region-wise voting patterns and results

-  Party performance comparison

-  Vote share and seat distribution analysis

-  Filter and drill-down capabilities

-  Easy-to-understand visual storytelling

 ## Tools & Technologies
- Power BI – Data visualization and dashboard creation

- Microsoft Excel / CSV – Data preprocessing
- GitHub – Version control and sharing
  

## Dashboard Insights
 
The dashboard provides insights such as:

- Total seats won by each party

- Vote share percentage

- State/region-wise results

- Winning margins and trends
## Dashboard overview
## 1.State Analysis
Provides a high-level view of voting patterns,party performance and trends across states.
## Key insights
- Identifies state-wise voting trends and patterns
- Highlights leading parties in each state
- Compares vote share vs seat share distribution
- Detects strongholds and weak regions of parties
- Shows regional shifts in voter preferences
- Helps in understanding overall state performance
